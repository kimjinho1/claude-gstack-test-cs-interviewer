# 03-11 동적 프로그래밍 (DP)

## 개념

**DP**: 큰 문제를 작은 부분 문제로 나누고, **중복 계산을 메모이제이션**으로 피하는 기법.

두 가지 조건:
1. **최적 부분 구조**: 최적해가 부분 문제의 최적해로 구성됨
2. **중복 부분 문제**: 같은 부분 문제가 반복 등장

```
피보나치 재귀 (중복 계산):
fib(5)
├── fib(4)
│   ├── fib(3)         fib(3)이 두 번!
│   │   ├── fib(2)
│   │   └── fib(1)
│   └── fib(2)
└── fib(3)             ← fib(3) 다시 계산!

DP (메모이제이션): 한 번 계산한 결과를 저장 → O(N)
```

---

## Top-Down (메모이제이션) vs Bottom-Up (타뷸레이션)

```
Top-Down:
  재귀 + 캐시 (dict/배열)
  코드 직관적, 필요한 부분만 계산
  재귀 스택 오버헤드, 스택 오버플로우 위험

Bottom-Up:
  반복문으로 작은 문제부터 채워감
  재귀 없음, 캐시 효율 좋음
  모든 부분 문제를 계산 (불필요한 것도)
  실무에서 선호
```

---

## 핵심 패턴

```
1D DP:    dp[i] = f(dp[i-1], dp[i-2], ...)
2D DP:    dp[i][j] = f(dp[i-1][j], dp[i][j-1], ...)
구간 DP:  dp[l][r] = f(dp[l][k], dp[k+1][r])
배낭 문제: dp[i][w] = max(dp[i-1][w], dp[i-1][w-weight[i]] + value[i])
```

## 예시 코드 (Python)

```python
from functools import lru_cache
from typing import Optional


# ── 1. 피보나치 — DP 기초 ────────────────────────────

def fib_recursive(n: int) -> int:          # O(2^N) — 지수
    if n <= 1: return n
    return fib_recursive(n-1) + fib_recursive(n-2)

def fib_memo(n: int, memo: dict = {}) -> int:  # O(N) Top-Down
    if n <= 1: return n
    if n in memo: return memo[n]
    memo[n] = fib_memo(n-1, memo) + fib_memo(n-2, memo)
    return memo[n]

def fib_dp(n: int) -> int:                 # O(N) Bottom-Up
    if n <= 1: return n
    dp = [0] * (n+1)
    dp[1] = 1
    for i in range(2, n+1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]

def fib_optimized(n: int) -> int:          # O(N), O(1) 공간
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a


# ── 2. 최장 공통 부분 수열 (LCS) ─────────────────────

def lcs(s1: str, s2: str) -> str:
    """
    두 문자열의 가장 긴 공통 부분 수열
    dp[i][j] = s1[:i], s2[:j]의 LCS 길이

    활용: diff, 버전 비교, 설정 파일 변경 감지
    """
    m, n = len(s1), len(s2)
    dp = [[0] * (n+1) for _ in range(m+1)]

    for i in range(1, m+1):
        for j in range(1, n+1):
            if s1[i-1] == s2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])

    # 역추적으로 실제 LCS 문자열 복원
    lcs_str = []
    i, j = m, n
    while i > 0 and j > 0:
        if s1[i-1] == s2[j-1]:
            lcs_str.append(s1[i-1])
            i -= 1; j -= 1
        elif dp[i-1][j] > dp[i][j-1]:
            i -= 1
        else:
            j -= 1
    return "".join(reversed(lcs_str))


# ── 3. 최장 증가 부분 수열 (LIS) ─────────────────────

def lis_dp(arr: list[int]) -> list[int]:
    """
    O(N²) DP
    dp[i] = arr[i]로 끝나는 LIS 길이
    """
    n = len(arr)
    dp     = [1] * n
    parent = [-1] * n

    for i in range(1, n):
        for j in range(i):
            if arr[j] < arr[i] and dp[j] + 1 > dp[i]:
                dp[i]     = dp[j] + 1
                parent[i] = j

    # 역추적
    end_idx = dp.index(max(dp))
    result = []
    while end_idx != -1:
        result.append(arr[end_idx])
        end_idx = parent[end_idx]
    return result[::-1]


# ── 4. 배낭 문제 (0/1 Knapsack) ─────────────────────

def knapsack(weights: list, values: list, capacity: int) -> int:
    """
    dp[i][w] = 물건 i개까지 고려, 무게 w 이하에서 최대 가치
    활용: 리소스 제약 최적화 (NMS 모니터링 항목 선택)
    """
    n = len(weights)
    dp = [[0] * (capacity+1) for _ in range(n+1)]

    for i in range(1, n+1):
        for w in range(capacity+1):
            dp[i][w] = dp[i-1][w]  # 물건 i 안 넣는 경우
            if weights[i-1] <= w:  # 물건 i 넣는 경우
                dp[i][w] = max(dp[i][w],
                               dp[i-1][w - weights[i-1]] + values[i-1])
    return dp[n][capacity]


# ── 5. 최소 편집 거리 (Edit Distance) ───────────────

def edit_distance(s1: str, s2: str) -> int:
    """
    삽입/삭제/교체 최소 횟수로 s1 → s2 변환
    dp[i][j] = s1[:i] → s2[:j] 최소 편집 횟수
    활용: 오타 교정, diff, DNS 유사 도메인 탐지
    """
    m, n = len(s1), len(s2)
    dp = [[0]*(n+1) for _ in range(m+1)]
    for i in range(m+1): dp[i][0] = i   # 삭제
    for j in range(n+1): dp[0][j] = j   # 삽입

    for i in range(1, m+1):
        for j in range(1, n+1):
            if s1[i-1] == s2[j-1]:
                dp[i][j] = dp[i-1][j-1]          # 변경 불필요
            else:
                dp[i][j] = 1 + min(dp[i-1][j],   # 삭제
                                   dp[i][j-1],    # 삽입
                                   dp[i-1][j-1])  # 교체
    return dp[m][n]


# ── 실행 ─────────────────────────────────────────────

print("=== 피보나치 ===")
for n in [10, 30, 50]:
    print(f"  fib({n}) = {fib_dp(n)}")

print("\n=== LCS (설정 diff) ===")
old_cfg = "vlan10porttrunkacl"
new_cfg = "vlan10portaccessacl"
print(f"  구 설정: {old_cfg}")
print(f"  신 설정: {new_cfg}")
print(f"  공통 부분: {lcs(old_cfg, new_cfg)}")

print("\n=== LIS ===")
traffic = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5]
print(f"  트래픽: {traffic}")
print(f"  증가 부분 수열: {lis_dp(traffic)}")

print("\n=== 배낭 문제 (모니터링 항목 선택) ===")
# NMS 모니터링: CPU 사용량, 항목별 (가중치=리소스, 가치=중요도)
items   = ["CPU%", "메모리%", "패킷수", "포트상태", "온도"]
weights = [3,      4,        2,       1,          2]    # 리소스 비용
values  = [9,      8,        6,       7,          5]    # 중요도
cap     = 7
print(f"  리소스 제한: {cap}")
print(f"  최대 중요도: {knapsack(weights, values, cap)}")

print("\n=== 편집 거리 (유사 도메인 탐지) ===")
pairs = [("google.com", "g00gle.com"), ("naver.com", "naverr.com")]
for a, b in pairs:
    d = edit_distance(a, b)
    print(f"  '{a}' ↔ '{b}': 편집거리={d} {'의심' if d<=2 else '정상'}")
```

## 면접 예상 질문

- Q: DP를 적용할 수 있는 조건은?
  A: ① 최적 부분 구조 — 전체 최적해가 부분 최적해의 조합. ② 중복 부분 문제 — 같은 부분 문제가 반복 등장. 최단 경로, 배낭 문제, 문자열 유사도가 해당. 그리디는 최적 부분 구조만 있으면 됨. 분할 정복은 중복 없는 경우.

- Q: Top-Down vs Bottom-Up 차이는?
  A: Top-Down(메모이제이션): 재귀로 필요한 부분만 계산, 코드 직관적. 단, 재귀 깊이 제한(Python 기본 1000) 주의. Bottom-Up(타뷸레이션): 반복문으로 작은 것부터 전부 채움, 재귀 없어 스택 오버플로우 없음, 캐시 지역성 좋음. Python 실무에서는 Bottom-Up + `@lru_cache` 혼용.

- Q: LCS와 편집 거리의 관계는?
  A: 둘 다 두 문자열의 유사도 측정. LCS는 공통 부분 수열의 길이, 편집 거리(Levenshtein)는 최소 삽입/삭제/교체 횟수. 편집 거리 = (m - LCS길이) + (n - LCS길이) (삽입/삭제만 허용 시). 오타 교정, git diff, 유사 도메인 탐지에 편집 거리 사용.
