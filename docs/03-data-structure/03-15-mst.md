# 03-15 최소 신장 트리 (Kruskal, Prim)

## 개념

**MST(Minimum Spanning Tree)**: 가중치 그래프에서 모든 노드를 연결하되, **간선 가중치 합이 최소**인 트리.

```
조건:
  - V개 노드, V-1개 간선 (트리 조건)
  - 사이클 없음
  - 모든 노드 연결

최단 경로 vs MST:
  최단 경로: 특정 두 노드 간 최소 비용 경로
  MST:       전체 네트워크 연결 최소 비용 (배선, 도로, 통신망)
```

| 알고리즘 | 방식 | 복잡도 | 유리한 경우 |
|---------|------|--------|-----------|
| **Kruskal** | 간선 정렬 후 그리디 (Union-Find) | O(E log E) | Sparse 그래프 (E 작을 때) |
| **Prim** | Min Heap + 정점 확장 | O((V+E) log V) | Dense 그래프 (E 클 때) |

---

## 동작 원리

### Kruskal

가중치 오름차순 정렬 → 사이클 없으면 간선 추가 (Union-Find로 사이클 감지).

```
그래프:
  A -1- B -3- D
  |    /|
  4   2  5
  |  /   |
  C      E

간선 정렬: (A-B,1), (B-C,2), (B-D,3), (A-C,4), (B-E,5)

1. (A-B,1) 추가: A-B 연결  [사이클 없음]
2. (B-C,2) 추가: B-C 연결  [사이클 없음]
3. (B-D,3) 추가: B-D 연결  [사이클 없음]
4. (A-C,4) 스킵: A-C 이미 A-B-C로 연결됨 [사이클!]
5. (B-E,5) 추가: B-E 연결  [사이클 없음]

결과: 4개 간선, 총 비용 = 1+2+3+5 = 11
```

### Prim

시작 노드에서 현재 MST와 연결된 간선 중 최소를 선택해 확장.

```
시작: A

1. A 선택 → 인접: (A-B,1),(A-C,4)  Min Heap 추가
2. (A-B,1) 선택 → B 방문 → 인접: (B-C,2),(B-D,3),(B-E,5) 추가
3. (B-C,2) 선택 → C 방문 → 인접: (A-C,4는 A 이미 방문) 스킵
4. (B-D,3) 선택 → D 방문
5. (A-C,4) 스킵 (C 이미 방문)
6. (B-E,5) 선택 → E 방문

결과: 동일하게 총 비용 = 11
```

## 예시 코드 (Python)

```python
import heapq
from collections import defaultdict


# ── Union-Find (Kruskal용) ────────────────────────────

class UnionFind:
    def __init__(self, nodes):
        self.parent = {n: n for n in nodes}
        self.rank   = {n: 0  for n in nodes}

    def find(self, x):           # 경로 압축
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y) -> bool:
        """합집합. 이미 같은 컴포넌트면 False (사이클)"""
        px, py = self.find(x), self.find(y)
        if px == py:
            return False
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        return True


# ── Kruskal ───────────────────────────────────────────

def kruskal(nodes: list, edges: list[tuple]) -> tuple[list, int]:
    """
    최소 신장 트리 — O(E log E)
    edges: [(weight, u, v), ...]
    returns: (MST 간선 목록, 총 비용)
    """
    uf  = UnionFind(nodes)
    mst = []
    total_cost = 0

    for w, u, v in sorted(edges):      # 가중치 오름차순
        if uf.union(u, v):             # 사이클이 아니면 추가
            mst.append((u, v, w))
            total_cost += w
            if len(mst) == len(nodes) - 1:   # V-1개 간선이면 완성
                break

    return mst, total_cost


# ── Prim ─────────────────────────────────────────────

def prim(graph: dict, start: str) -> tuple[list, int]:
    """
    최소 신장 트리 — O((V+E) log V)
    graph: {node: [(neighbor, weight), ...]}
    returns: (MST 간선 목록, 총 비용)
    """
    visited    = {start}
    heap       = [(w, start, v) for v, w in graph.get(start, [])]
    heapq.heapify(heap)
    mst        = []
    total_cost = 0

    while heap:
        w, u, v = heapq.heappop(heap)
        if v in visited:
            continue
        visited.add(v)
        mst.append((u, v, w))
        total_cost += w
        for neighbor, weight in graph.get(v, []):
            if neighbor not in visited:
                heapq.heappush(heap, (weight, v, neighbor))

    return mst, total_cost


# ── 실전: 스위치 네트워크 배선 최적화 ─────────────────

def network_wiring_optimization():
    """
    신규 사무실 스위치 배선 시 케이블 비용 최소화
    가중치 = 케이블 길이(m)
    """
    # 무방향 그래프 (스위치 간 연결 비용)
    nodes = ["Core", "Dist1", "Dist2", "Access1", "Access2", "Access3"]
    edges = [
        (10, "Core",   "Dist1"),
        (15, "Core",   "Dist2"),
        (5,  "Dist1",  "Access1"),
        (8,  "Dist1",  "Access2"),
        (7,  "Dist2",  "Access2"),   # Access2는 양쪽 Dist에 연결 가능
        (6,  "Dist2",  "Access3"),
        (20, "Core",   "Access1"),   # 직접 연결 가능하나 비쌈
    ]

    print("  [Kruskal]")
    mst_k, cost_k = kruskal(nodes, edges)
    print(f"  총 케이블 비용: {cost_k}m")
    for u, v, w in mst_k:
        print(f"    {u} ↔ {v}: {w}m")

    # Prim용 인접 리스트 변환
    graph = defaultdict(list)
    for w, u, v in edges:
        graph[u].append((v, w))
        graph[v].append((u, w))

    print("\n  [Prim]")
    mst_p, cost_p = prim(dict(graph), "Core")
    print(f"  총 케이블 비용: {cost_p}m")
    for u, v, w in mst_p:
        print(f"    {u} ↔ {v}: {w}m")

    assert cost_k == cost_p, "MST 비용 불일치!"
    print(f"\n  → 절약된 비용: {sum(w for w,_,_ in edges) - cost_k}m")


# ── MST 속성 확인 ─────────────────────────────────────

def verify_mst_properties(nodes, edges):
    """MST 검증: V-1 간선, 연결, 사이클 없음"""
    mst, cost = kruskal(nodes, edges)

    # 1. 간선 수 = V-1
    assert len(mst) == len(nodes) - 1, f"간선 수 오류: {len(mst)}"

    # 2. 모든 노드 포함
    mst_nodes = set()
    for u, v, _ in mst:
        mst_nodes.add(u); mst_nodes.add(v)
    assert set(nodes) == mst_nodes, "노드 누락"

    # 3. 사이클 없음 (BFS로 확인)
    adj = defaultdict(list)
    for u, v, _ in mst:
        adj[u].append(v); adj[v].append(u)
    visited = set()
    queue = [nodes[0]]
    visited.add(nodes[0])
    while queue:
        node = queue.pop(0)
        for neighbor in adj[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
    assert visited == set(nodes), "연결 그래프가 아님"

    return True


# ── 실행 ─────────────────────────────────────────────

print("=== 스위치 네트워크 배선 최적화 ===")
network_wiring_optimization()

print("\n=== MST 속성 검증 ===")
nodes = ["A", "B", "C", "D", "E"]
edges = [(1,"A","B"),(2,"B","C"),(3,"B","D"),(4,"A","C"),(5,"B","E")]
result = verify_mst_properties(nodes, edges)
mst, cost = kruskal(nodes, edges)
print(f"  검증 통과: {result}")
print(f"  MST 간선: {[(u,v,w) for u,v,w in mst]}")
print(f"  총 비용: {cost}")
```

## 면접 예상 질문

- Q: Kruskal vs Prim 선택 기준은?
  A: Sparse 그래프(E ≈ V)는 Kruskal — 간선 정렬이 E log E로 간선이 적으면 빠름. Dense 그래프(E ≈ V²)는 Prim — Min Heap으로 인접 간선만 관리. 실무에서 네트워크 토폴로지는 보통 Sparse라 Kruskal이 자주 쓰임.

- Q: Kruskal이 그리디인데 왜 항상 최적인가?
  A: Cut Property로 증명. 임의의 Cut(노드 집합 S와 V-S의 분리)에서 양쪽을 잇는 최소 가중치 간선은 반드시 MST에 포함됨. Kruskal은 매번 안전한(사이클 없는) 최소 간선을 추가하므로 이 속성을 만족 → 항상 MST 보장.

- Q: MST와 최단 경로의 차이는?
  A: MST는 전체 네트워크 연결 비용 최소화 (V-1개 간선, 모든 노드 연결). 최단 경로는 특정 두 노드 간 최소 비용 경로. MST 경로가 최단 경로가 아닐 수 있음. 예: A-B-C에서 A→C MST 경로 비용 > A→C 직접 연결. 용도: MST=인프라 배선/배관, 최단경로=라우팅/내비게이션.

- Q: 음수 가중치 간선이 있을 때 MST는?
  A: Kruskal, Prim 모두 음수 가중치 허용. 음수 간선도 정렬 후 처리하면 됨. Dijkstra와 달리 MST는 그리디 선택이 전체 최적을 보장하므로 음수 가중치에도 무관. 단, 음수 사이클이 있으면 MST 개념 자체가 무의미 (트리가 아님).
