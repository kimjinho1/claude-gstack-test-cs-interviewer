# 03-07 Tree (BST, AVL, Red-Black Tree)

## 개념

**트리**: 계층적 구조. 루트에서 리프까지 유일한 경로.
**BST**: 왼쪽 < 루트 < 오른쪽. 탐색 O(log N) (균형일 때).
**AVL**: BST + 자동 균형. 높이 차이 ≤ 1 보장.
**Red-Black Tree**: BST + 색상 규칙으로 느슨한 균형. 실무 표준.

---

## 동작 원리

### BST (Binary Search Tree)

```
삽입 [5, 3, 7, 1, 4, 6, 8]:
       5
      / \
     3   7
    / \ / \
   1  4 6  8

탐색(4): 5>4 → 왼쪽, 3<4 → 오른쪽, 4==4 → O(log N)

최악의 경우 (정렬된 순서로 삽입: 1,2,3,4,5):
  1
   \
    2
     \
      3  → 사실상 LinkedList → 탐색 O(N)
```

### AVL Tree — 자가 균형 BST

**Balance Factor** = 왼쪽 서브트리 높이 - 오른쪽 서브트리 높이

```
균형 조건: |BF| ≤ 1 (모든 노드)

불균형 발생 시 → 회전(Rotation)으로 복구:

1. LL 불균형 → 우회전 (Right Rotation)
       z(BF=2)        y
      /           →  / \
     y(BF=1)        x   z
    /
   x

2. RR 불균형 → 좌회전 (Left Rotation)
   z(BF=-2)              y
    \           →       / \
     y(BF=-1)          z   x
      \
       x

3. LR 불균형 → 좌회전 후 우회전 (Left-Right)
4. RL 불균형 → 우회전 후 좌회전 (Right-Left)
```

### Red-Black Tree — 실무 표준

**규칙**:
```
1. 모든 노드는 RED 또는 BLACK
2. 루트는 BLACK
3. 리프(NIL)는 BLACK
4. RED 노드의 자식은 항상 BLACK (RED 연속 불가)
5. 루트→리프 경로의 BLACK 노드 수는 모두 동일

→ 높이 ≤ 2 × log(N+1) 보장 (엄격하지 않은 균형)

AVL vs RBT:
  AVL: |BF| ≤ 1, 더 엄격, 탐색 빠름, 삽입/삭제 회전 많음
  RBT: 느슨한 균형,  삽입/삭제 빠름, 실무에서 선호

실제 사용:
  Java TreeMap, TreeSet  → Red-Black Tree
  C++ std::map, std::set → Red-Black Tree
  Linux CFS 스케줄러     → Red-Black Tree (task들 관리)
  Nginx timer 관리       → Red-Black Tree
```

### 트리 순회 (Traversal)

```
       4
      / \
     2   6
    / \ / \
   1  3 5  7

전위(Pre-order): 루트→왼→오  → 4,2,1,3,6,5,7  (트리 복사/직렬화)
중위(In-order):  왼→루트→오  → 1,2,3,4,5,6,7  (BST: 정렬된 순서)
후위(Post-order): 왼→오→루트 → 1,3,2,5,7,6,4  (트리 삭제)
레벨(Level-order): BFS       → 4,2,6,1,3,5,7  (레벨별 처리)
```

## 예시 코드 (Python)

```python
from __future__ import annotations
from typing import Optional
from collections import deque


# ── BST 구현 ─────────────────────────────────────────

class BSTNode:
    def __init__(self, key, val=None):
        self.key   = key
        self.val   = val
        self.left  = self.right = None


class BST:
    def __init__(self):
        self.root: Optional[BSTNode] = None

    def insert(self, key, val=None):
        self.root = self._insert(self.root, key, val)

    def _insert(self, node, key, val):
        if node is None:
            return BSTNode(key, val)
        if key < node.key:
            node.left  = self._insert(node.left,  key, val)
        elif key > node.key:
            node.right = self._insert(node.right, key, val)
        else:
            node.val = val   # 중복 키: 값 업데이트
        return node

    def search(self, key) -> Optional[BSTNode]:  # O(log N) 균형 시
        node = self.root
        while node:
            if key == node.key:   return node
            elif key < node.key:  node = node.left
            else:                 node = node.right
        return None

    def delete(self, key):
        self.root = self._delete(self.root, key)

    def _delete(self, node, key):
        if node is None: return None
        if key < node.key:
            node.left  = self._delete(node.left, key)
        elif key > node.key:
            node.right = self._delete(node.right, key)
        else:
            if node.left is None:  return node.right  # 자식 0~1개
            if node.right is None: return node.left
            # 자식 2개: 오른쪽 서브트리 최솟값(후계자)으로 교체
            successor = self._min_node(node.right)
            node.key, node.val = successor.key, successor.val
            node.right = self._delete(node.right, successor.key)
        return node

    def _min_node(self, node):
        while node.left:
            node = node.left
        return node

    def inorder(self) -> list:     # 정렬된 순서
        result = []
        def _in(node):
            if node:
                _in(node.left)
                result.append(node.key)
                _in(node.right)
        _in(self.root)
        return result

    def height(self) -> int:
        def _h(node):
            if node is None: return 0
            return 1 + max(_h(node.left), _h(node.right))
        return _h(self.root)


# ── AVL Tree ──────────────────────────────────────────

class AVLNode:
    def __init__(self, key):
        self.key    = key
        self.left   = self.right = None
        self.height = 1


class AVLTree:
    def __init__(self):
        self.root = None

    def _height(self, n): return n.height if n else 0
    def _bf(self, n):     return self._height(n.left) - self._height(n.right)
    def _update(self, n): n.height = 1 + max(self._height(n.left), self._height(n.right))

    def _rotate_right(self, z):
        y = z.left
        z.left = y.right
        y.right = z
        self._update(z); self._update(y)
        return y

    def _rotate_left(self, z):
        y = z.right
        z.right = y.left
        y.left = z
        self._update(z); self._update(y)
        return y

    def _rebalance(self, node):
        self._update(node)
        bf = self._bf(node)
        if bf > 1:   # LL or LR
            if self._bf(node.left) < 0:           # LR
                node.left = self._rotate_left(node.left)
            return self._rotate_right(node)
        if bf < -1:  # RR or RL
            if self._bf(node.right) > 0:          # RL
                node.right = self._rotate_right(node.right)
            return self._rotate_left(node)
        return node

    def insert(self, key):
        self.root = self._insert(self.root, key)

    def _insert(self, node, key):
        if node is None: return AVLNode(key)
        if key < node.key:   node.left  = self._insert(node.left, key)
        elif key > node.key: node.right = self._insert(node.right, key)
        return self._rebalance(node)

    def height(self):
        return self._height(self.root)

    def inorder(self) -> list:
        result = []
        def _in(n):
            if n:
                _in(n.left)
                result.append(n.key)
                _in(n.right)
        _in(self.root)
        return result


# ── 실전: 스위치 라우팅 테이블 (BST 기반) ────────────

class RoutingTable:
    """
    목적지 IP 프리픽스 → 다음 홉 매핑
    BST로 관리하면 O(log N) 탐색
    실제 라우터는 Trie(Patricia tree) 사용 — 최장 프리픽스 매칭
    """
    def __init__(self):
        self._bst = BST()

    def add_route(self, prefix: int, next_hop: str):
        self._bst.insert(prefix, next_hop)

    def lookup(self, dest: int) -> Optional[str]:
        node = self._bst.search(dest)
        return node.val if node else None

    def all_routes(self) -> list[int]:
        return self._bst.inorder()


# ── 실행 ─────────────────────────────────────────────

print("=== BST ===")
bst = BST()
for k in [5, 3, 7, 1, 4, 6, 8]:
    bst.insert(k)
print(f"  중위 순회 (정렬): {bst.inorder()}")
print(f"  높이: {bst.height()}")
bst.delete(3)
print(f"  3 삭제 후: {bst.inorder()}")

print("\n=== BST vs AVL 높이 비교 (정렬된 삽입) ===")
bst2 = BST()
avl  = AVLTree()
for k in range(1, 16):    # 1~15 정렬 순서 삽입
    bst2.insert(k)
    avl.insert(k)
print(f"  BST 높이: {bst2.height()} (편향 트리 — 선형 탐색)")
print(f"  AVL 높이: {avl.height()} (균형 유지 — log N 탐색)")
print(f"  AVL 중위: {avl.inorder()}")

print("\n=== 라우팅 테이블 ===")
rt = RoutingTable()
rt.add_route(10, "192.168.1.1")
rt.add_route(20, "192.168.1.2")
rt.add_route(30, "192.168.1.3")
print(f"  라우트 20 조회: {rt.lookup(20)}")
print(f"  전체 경로(정렬): {rt.all_routes()}")
```

## 면접 예상 질문

- Q: BST의 최악 O(N)이 발생하는 경우와 AVL로 해결하는 방법은?
  A: 정렬된 순서로 삽입 시 편향 트리(LinkedList 형태) 생성 → 탐색 O(N). AVL은 삽입/삭제 후 Balance Factor(BF) 확인, |BF|>1이면 회전(Rotation)으로 즉시 균형 복구 → 항상 O(log N) 보장. 단, 삽입/삭제 시 회전 연산 오버헤드 있음.

- Q: Red-Black Tree와 AVL Tree의 차이는?
  A: AVL은 |BF|≤1 엄격한 균형 → 탐색 최적화. RBT는 색상 규칙으로 높이 ≤ 2log(N+1)의 느슨한 균형 → 삽입/삭제 회전 횟수 최대 2~3회(AVL은 많을 수 있음). 읽기가 많으면 AVL, 쓰기가 많으면 RBT 선호. 실무(Java TreeMap, Linux 스케줄러)는 대부분 RBT.

- Q: BST 중위 순회가 정렬된 결과를 내는 이유는?
  A: BST 성질: 왼쪽 서브트리의 모든 값 < 루트 < 오른쪽 서브트리의 모든 값. 중위 순회(왼→루트→오)는 이 성질을 재귀적으로 따라가므로 항상 오름차순 출력. 역중위(오→루트→왼)는 내림차순.
