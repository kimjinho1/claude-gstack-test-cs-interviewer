# 03-08 Heap / Priority Queue

## 개념

**Heap**: 부모가 항상 자식보다 크거나(Max Heap) 작은(Min Heap) **완전 이진 트리**.
**Priority Queue**: Heap으로 구현. 항상 최솟값/최댓값을 O(log N)에 삽입/추출.

```
Min Heap:       Max Heap:
     1                9
    / \              / \
   3   2            7   8
  / \ /            / \
 5  4 6           4   5
```

---

## 동작 원리

### 배열로 Heap 구현

완전 이진 트리는 배열에 레벨 순서로 저장:

```
인덱스:  0  1  2  3  4  5  6
값:     [1, 3, 2, 5, 4, 6, 7]  (1-indexed면 인덱스 1부터)

부모/자식 인덱스 계산 (0-indexed):
  부모(i)    = (i-1) // 2
  왼쪽 자식  = 2*i + 1
  오른쪽 자식 = 2*i + 2

→ 포인터 없이 배열만으로 트리 구조 표현 → 캐시 친화적
```

### 삽입 (Push) — O(log N)

```
Min Heap에 0 삽입:
  1. 배열 끝에 추가: [1, 3, 2, 5, 4, 6, 7, 0]
  2. Bubble Up: 부모와 비교하며 올라감
     0 < 5(부모) → swap → [1, 3, 2, 0, 4, 6, 7, 5]
     0 < 3(부모) → swap → [1, 0, 2, 3, 4, 6, 7, 5]
     0 < 1(루트) → swap → [0, 1, 2, 3, 4, 6, 7, 5]
  3. 완료 (최대 log N 비교)
```

### 추출 (Pop) — O(log N)

```
Min Heap에서 최솟값(루트) 추출:
  1. 루트값 저장: min = arr[0] = 0
  2. 마지막 원소를 루트로: arr[0] = arr[-1]
     [5, 1, 2, 3, 4, 6, 7]
  3. Bubble Down: 자식 중 작은 것과 비교하며 내려감
     5 > min(1,2)=1 → swap with arr[1]
     → [1, 5, 2, 3, 4, 6, 7]
     5 > min(3,4)=3 → swap with arr[3]
     → [1, 3, 2, 5, 4, 6, 7]
  4. 완료, min=0 반환
```

### Heapify — O(N)

배열에서 Heap 만들기. 단순히 N번 push하면 O(N log N)이지만, 아래에서 위로 heapify하면 O(N).

```
수학적 증명:
  높이 h인 노드에서 heapify 비용 = O(h)
  높이 h에 있는 노드 수 ≤ N / 2^(h+1)
  총 비용 = Σ (N/2^h × h) ≈ O(N)
```

## 예시 코드 (Python)

```python
import heapq
from dataclasses import dataclass, field
from typing import Optional


# ── Min Heap 직접 구현 ───────────────────────────────

class MinHeap:
    def __init__(self):
        self._data: list = []

    def push(self, val):           # O(log N)
        self._data.append(val)
        self._bubble_up(len(self._data) - 1)

    def pop(self) -> int:          # O(log N)
        if not self._data:
            raise IndexError("Heap is empty")
        self._swap(0, len(self._data) - 1)
        val = self._data.pop()
        self._bubble_down(0)
        return val

    def peek(self):                # O(1)
        if not self._data:
            raise IndexError("Heap is empty")
        return self._data[0]

    def _bubble_up(self, i):
        while i > 0:
            parent = (i - 1) // 2
            if self._data[i] < self._data[parent]:
                self._swap(i, parent)
                i = parent
            else:
                break

    def _bubble_down(self, i):
        n = len(self._data)
        while True:
            smallest, l, r = i, 2*i+1, 2*i+2
            if l < n and self._data[l] < self._data[smallest]: smallest = l
            if r < n and self._data[r] < self._data[smallest]: smallest = r
            if smallest == i: break
            self._swap(i, smallest)
            i = smallest

    def _swap(self, i, j):
        self._data[i], self._data[j] = self._data[j], self._data[i]

    def __len__(self):   return len(self._data)
    def __repr__(self):  return f"MinHeap{self._data}"

    @classmethod
    def heapify(cls, arr: list) -> 'MinHeap':
        """O(N) Heapify"""
        h = cls()
        h._data = arr[:]
        # 리프가 아닌 마지막 노드부터 역순으로 bubble_down
        for i in range(len(h._data) // 2 - 1, -1, -1):
            h._bubble_down(i)
        return h


# ── Python heapq 모듈 활용 ───────────────────────────
# heapq는 Min Heap. Max Heap은 값에 -1을 곱해서 사용.

def top_k_largest(arr: list, k: int) -> list:
    """
    상위 K개 최댓값 — O(N log K)
    Min Heap 크기를 K로 유지 → heap[0]이 K번째 최댓값
    """
    heap = []
    for val in arr:
        heapq.heappush(heap, val)
        if len(heap) > k:
            heapq.heappop(heap)   # K+1번째로 작은 것 제거
    return sorted(heap, reverse=True)


def merge_sorted_lists(lists: list[list]) -> list:
    """
    K개의 정렬된 리스트 병합 — O(N log K)
    각 리스트의 현재 최솟값을 Heap에 유지
    """
    heap = []  # (값, 리스트 인덱스, 원소 인덱스)
    for i, lst in enumerate(lists):
        if lst:
            heapq.heappush(heap, (lst[0], i, 0))

    result = []
    while heap:
        val, li, ei = heapq.heappop(heap)
        result.append(val)
        if ei + 1 < len(lists[li]):
            heapq.heappush(heap, (lists[li][ei+1], li, ei+1))
    return result


# ── 우선순위 큐: 알람/태스크 스케줄러 ────────────────

@dataclass(order=True)
class AlertTask:
    priority: int                              # 낮을수록 먼저
    severity: str = field(compare=False)
    message:  str = field(compare=False)
    device:   str = field(compare=False)


class AlertScheduler:
    """
    NMS 알람 우선순위 처리기
    CRITICAL > HIGH > MEDIUM > LOW 순으로 처리
    """
    SEVERITY_MAP = {"CRITICAL": 0, "HIGH": 1, "MEDIUM": 2, "LOW": 3}

    def __init__(self):
        self._heap: list = []

    def add_alert(self, severity: str, message: str, device: str):
        priority = self.SEVERITY_MAP.get(severity, 99)
        heapq.heappush(self._heap, AlertTask(priority, severity, message, device))

    def process_next(self) -> Optional[AlertTask]:
        return heapq.heappop(self._heap) if self._heap else None

    def pending(self) -> int:
        return len(self._heap)


# ── 실행 ─────────────────────────────────────────────

print("=== Min Heap ===")
mh = MinHeap()
for v in [5, 3, 7, 1, 4, 2]:
    mh.push(v)
print(f"  힙: {mh}")
print(f"  peek: {mh.peek()}")
print(f"  pop 순서: ", end="")
while mh:
    print(mh.pop(), end=" ")
print()

print("\n=== Heapify O(N) ===")
arr = [5, 3, 7, 1, 4, 2, 9]
h2 = MinHeap.heapify(arr)
print(f"  원본: {arr}")
print(f"  힙:  {h2}")

print("\n=== Top-K ===")
data = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3]
print(f"  데이터: {data}")
print(f"  Top-3:  {top_k_largest(data, 3)}")

print("\n=== K-way 병합 ===")
lists = [[1, 4, 7], [2, 5, 8], [3, 6, 9]]
print(f"  병합: {merge_sorted_lists(lists)}")

print("\n=== NMS 알람 우선순위 ===")
sched = AlertScheduler()
sched.add_alert("LOW",      "포트 사용률 80%",   "SW-01")
sched.add_alert("CRITICAL", "코어 스위치 다운",  "Core-SW")
sched.add_alert("HIGH",     "CPU 90% 초과",      "Dist-SW-1")
sched.add_alert("MEDIUM",   "팬 이상",           "SW-03")
sched.add_alert("CRITICAL", "업링크 단절",        "Access-SW-5")

print(f"  대기 알람: {sched.pending()}개")
while sched.pending():
    alert = sched.process_next()
    print(f"  [{alert.severity:8s}] {alert.device}: {alert.message}")
```

## 면접 예상 질문

- Q: Heap과 정렬된 배열로 Priority Queue를 구현할 때 차이는?
  A: 정렬 배열: 삽입 O(N)(삽입 위치 찾고 이동), 추출 O(1). Heap: 삽입 O(log N), 추출 O(log N). 삽입이 잦으면 Heap이 유리. 조회만 많으면 정렬 배열도 괜찮음. 실무에서는 Heap 사용이 표준.

- Q: Heapify가 O(N)인 이유는?
  A: N번 push(각 O(log N)) = O(N log N)이 아니라, 아래에서 위로 bubble_down하면 각 노드의 비용이 해당 노드의 높이에 비례. 높이 h의 노드 수는 ≈ N/2^h. 총 비용 Σ(h × N/2^h) ≈ 2N = O(N). 비직관적이지만 수학적으로 O(N).

- Q: Python heapq로 Max Heap을 만드는 방법은?
  A: Python heapq는 Min Heap만 제공. Max Heap: 값에 -1을 곱해서 push하고, pop 후 -1 곱해서 원래 값 복원. 또는 `(-val, val)` 튜플로 저장. 객체는 `__lt__` 역순으로 정의하거나 `dataclass(order=True)`로 비교 필드 순서 조정.
