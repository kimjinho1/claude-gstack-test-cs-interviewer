# 01-14 CDN (Content Delivery Network)

## 개념

전 세계 여러 곳에 **엣지 서버(POP, Point of Presence)** 를 두고, 사용자에게 가장 가까운 서버에서 콘텐츠를 제공하는 분산 네트워크.

```
오리진 서버 (한국)
     │
     ├── 엣지 서버 (서울)   ← 한국 사용자
     ├── 엣지 서버 (도쿄)   ← 일본 사용자
     ├── 엣지 서버 (LA)     ← 미국 서부 사용자
     └── 엣지 서버 (런던)   ← 유럽 사용자
```

---

## 동작 원리

### 캐시 동작 흐름

```
① 사용자 → 엣지 서버: "image.png 줘"
② 엣지 서버: 캐시 확인
   → Cache HIT: 바로 응답 (오리진 서버 거치지 않음)
   → Cache MISS: 오리진 서버에서 가져와 캐시 저장 후 응답

③ 이후 요청:
   → 캐시 있으면 엣지에서 직접 응답 (빠름)
   → TTL 만료 시 오리진에서 갱신
```

### CDN이 해결하는 문제

```
문제: 서울 서버 → 미국 사용자 응답
  물리 거리 약 1만km → RTT 약 200ms
  + 패킷 손실, 라우팅 홉 증가

CDN 적용:
  LA 엣지 서버 → 미국 사용자
  RTT 약 5ms → 40배 빠름
```

### 캐시 가능한 콘텐츠 vs 아닌 것

```
CDN 캐시 적합:
  - 이미지, CSS, JS (정적 파일)
  - API 응답 (변경이 드문 것)
  - 동영상, 폰트

CDN 캐시 부적합:
  - 사용자별 개인화 데이터
  - 실시간 데이터 (주식, 채팅)
  - 인증이 필요한 API 응답
```

### Cache-Control 헤더

```
Cache-Control: public, max-age=86400   → CDN + 브라우저 1일 캐시
Cache-Control: private, max-age=3600  → 브라우저만 1시간 캐시 (CDN 불가)
Cache-Control: no-cache               → 항상 검증 후 사용
Cache-Control: no-store               → 캐시 안 함
```

### CDN의 추가 기능

| 기능 | 설명 |
|------|------|
| DDoS 방어 | 분산된 엣지가 공격 트래픽 흡수 |
| TLS 종료 | 엣지에서 TLS 처리 → 오리진 부담 감소 |
| 이미지 최적화 | WebP 변환, 리사이징 |
| 압축 | gzip/brotli 압축 |
| WAF | 웹 방화벽 (SQL Injection, XSS 차단) |

## 예시 코드 (Python)

```python
import time
from dataclasses import dataclass, field
from typing import Optional


@dataclass
class CacheEntry:
    content: bytes
    content_type: str
    max_age: int  # seconds
    cached_at: float = field(default_factory=time.time)

    def is_expired(self) -> bool:
        return time.time() - self.cached_at > self.max_age


class EdgeServer:
    """CDN 엣지 서버"""
    def __init__(self, region: str, origin_url: str):
        self.region = region
        self.origin_url = origin_url
        self._cache: dict[str, CacheEntry] = {}
        self.hits = 0
        self.misses = 0

    def request(self, path: str) -> tuple[bytes, str, bool]:
        """
        Returns: (content, content_type, cache_hit)
        """
        entry = self._cache.get(path)

        # Cache HIT
        if entry and not entry.is_expired():
            self.hits += 1
            print(f"[{self.region}] HIT: {path}")
            return entry.content, entry.content_type, True

        # Cache MISS → 오리진에서 가져옴
        self.misses += 1
        print(f"[{self.region}] MISS: {path} → 오리진 요청")
        content, content_type, max_age = self._fetch_from_origin(path)

        # public 캐시만 저장
        if max_age > 0:
            self._cache[path] = CacheEntry(content, content_type, max_age)
            print(f"[{self.region}] 캐시 저장: {path} (TTL={max_age}s)")

        return content, content_type, False

    def _fetch_from_origin(self, path: str) -> tuple[bytes, str, int]:
        """오리진 서버 요청 시뮬레이션"""
        time.sleep(0.1)  # 오리진 레이턴시 시뮬레이션
        resources = {
            "/logo.png":    (b"PNG_DATA", "image/png", 86400),
            "/style.css":   (b"CSS_DATA", "text/css", 3600),
            "/api/status":  (b'{"ok":true}', "application/json", 0),  # no-cache
        }
        return resources.get(path, (b"404", "text/plain", 0))

    def invalidate(self, path: str):
        """캐시 무효화 (배포 시 사용)"""
        if path in self._cache:
            del self._cache[path]
            print(f"[{self.region}] 캐시 무효화: {path}")

    def stats(self):
        total = self.hits + self.misses
        ratio = self.hits / total * 100 if total else 0
        print(f"[{self.region}] HIT율: {ratio:.1f}% ({self.hits}/{total})")


# 시뮬레이션
edge = EdgeServer(region="Seoul-POP", origin_url="https://origin.company.com")

print("=== 첫 요청 (MISS) ===")
edge.request("/logo.png")
edge.request("/style.css")

print("\n=== 반복 요청 (HIT) ===")
for _ in range(5):
    edge.request("/logo.png")

print("\n=== no-cache 리소스 ===")
edge.request("/api/status")
edge.request("/api/status")  # 캐시 안 됨 → 항상 MISS

print("\n=== 배포 후 캐시 무효화 ===")
edge.invalidate("/style.css")
edge.request("/style.css")  # MISS → 오리진에서 다시

edge.stats()
```

## 면접 예상 질문

- Q: CDN이란 무엇이고 왜 사용하나?
  A: 전 세계 엣지 서버에 콘텐츠를 캐시해 사용자와 가까운 서버에서 응답하는 분산 네트워크. 레이턴시 감소, 오리진 서버 부하 감소, DDoS 방어, 가용성 향상 목적.

- Q: CDN 캐시 무효화(Cache Invalidation)란?
  A: 배포나 콘텐츠 변경 시 엣지 서버의 캐시를 강제로 만료시키는 것. TTL 만료 전에 갱신이 필요할 때 사용. 방법: CDN API로 특정 경로 purge, 파일명에 해시 포함(cache busting).

- Q: Cache-Control: no-cache vs no-store 차이는?
  A: no-cache는 캐시는 하되 사용 전 서버에 유효성 검증(ETag/Last-Modified). no-store는 캐시 자체를 하지 않음. 개인정보, 금융 데이터에 no-store 사용.
