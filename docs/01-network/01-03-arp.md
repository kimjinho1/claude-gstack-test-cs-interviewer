# 01-03 ARP (Address Resolution Protocol)

## 개념

IP 주소는 알지만 **MAC 주소를 모를 때** 브로드캐스트로 물어보는 프로토콜 (RFC 826).
L3(IP 주소)와 L2(MAC 주소)를 연결하는 다리 역할.

- 동작 계층: L2/L3 경계 (EtherType 0x0806, IP 패킷이 아님)
- 적용 범위: 같은 L2 네트워크(브로드캐스트 도메인) 안에서만 동작

---

## 동작 원리

### 같은 서브넷 내 통신

```
PC-A (192.168.1.10 / AA:BB:CC:11:22:33)
PC-B (192.168.1.20 / AA:BB:CC:44:55:66)

① PC-A: ARP 테이블에 192.168.1.20 없음
   → ARP Request 브로드캐스트 전송
     [ src_mac=AA:BB:CC:11:22:33 | dst_mac=FF:FF:FF:FF:FF:FF ]
     [ src_ip=192.168.1.10 | dst_ip=192.168.1.20 ]

② 스위치: 브로드캐스트 → 전체 flooding / PC-A MAC 학습

③ PC-B: "192.168.1.20은 나야"
   → ARP Reply 유니캐스트
     [ src_mac=AA:BB:CC:44:55:66 | dst_mac=AA:BB:CC:11:22:33 ]
     [ src_ip=192.168.1.20 | dst_ip=192.168.1.10 ]

④ PC-A: ARP 테이블 저장
   192.168.1.20 → AA:BB:CC:44:55:66  (TTL 시작)

⑤ 이후 통신: ARP 없이 바로 유니캐스트 전송
```

### 다른 서브넷 통신 (게이트웨이 경유)

목적지가 다른 네트워크면 PC는 **게이트웨이 MAC**을 ARP로 조회함.

```
PC-A (192.168.1.10) → 서버 (10.0.0.5)  ← 다른 서브넷

① PC-A OS: "10.0.0.5는 내 서브넷 밖 → 게이트웨이(192.168.1.1)로 보내야 함"
② ARP Request: "192.168.1.1의 MAC 알려줘"
③ 게이트웨이(L3 스위치 SVI or 라우터) → ARP Reply
④ 프레임 전송:
   dst_mac = 게이트웨이 MAC   ← L2: 다음 홉
   dst_ip  = 10.0.0.5         ← L3: 최종 목적지
```

**핵심: IP(dst_ip)는 최종 목적지, MAC(dst_mac)은 다음 홉(next-hop)만 가리킴.**
라우터를 거칠 때마다 MAC은 바뀌지만 IP는 유지됨.

### VLAN 환경에서 ARP

ARP는 브로드캐스트 → **같은 VLAN 안에서만** 전달됨.

```
VLAN 10의 PC-A가 ARP Request 전송
→ 스위치: VLAN 10에 속한 포트로만 flooding
→ VLAN 20 장비에는 도달하지 않음
```

VLAN 10 PC가 VLAN 20 서버에 통신하려면:
1. 게이트웨이(L3 스위치 SVI) MAC을 ARP로 조회
2. L3 스위치가 VLAN 간 라우팅 처리
3. L3 스위치가 VLAN 20에서 서버 MAC을 ARP로 조회

## Gratuitous ARP (GARP)

자신의 IP를 **스스로 브로드캐스트**하는 ARP.

```
"나는 192.168.1.10이고 내 MAC은 AA:BB:CC:11:22:33이야" → 전체 브로드캐스트
```

**용도**
- IP 충돌 감지: 응답이 오면 같은 IP를 쓰는 장비가 있다는 뜻
- ARP 캐시 강제 갱신: IP 변경/장비 교체/failover 시 주변 장비 ARP 테이블 업데이트
- 스위치/AP 재부팅 후 네트워크 복귀 시 전송

### ARP 테이블 TTL

ARP 항목은 일정 시간 후 만료 (장비마다 다름):

| OS / 장비 | TTL |
|-----------|-----|
| Windows | ~2분 |
| Linux | ~1분 |
| Cisco IOS | 4시간 |

만료 후 해당 IP로 통신 시 다시 ARP Request 전송.

## 예시 코드 (Python)

```python
import time
from dataclasses import dataclass, field
from typing import Optional

@dataclass
class ArpEntry:
    ip: str
    mac: str
    created_at: float = field(default_factory=time.time)
    ttl: int = 120  # seconds

    def is_expired(self) -> bool:
        return time.time() - self.created_at > self.ttl


class ArpTable:
    """호스트의 ARP 테이블"""
    def __init__(self):
        self._table: dict[str, ArpEntry] = {}

    def lookup(self, ip: str) -> Optional[str]:
        entry = self._table.get(ip)
        if entry and not entry.is_expired():
            return entry.mac
        if entry:
            del self._table[ip]  # 만료 항목 제거
        return None

    def learn(self, ip: str, mac: str):
        self._table[ip] = ArpEntry(ip=ip, mac=mac)
        print(f"[ARP] 학습: {ip} → {mac}")

    def show(self):
        print("\n[ARP Table]")
        for ip, entry in self._table.items():
            status = "expired" if entry.is_expired() else "valid"
            print(f"  {ip:15} → {entry.mac}  ({status})")


class Host:
    """네트워크 호스트 (PC, 서버 등)"""
    def __init__(self, ip: str, mac: str, gateway_ip: str, subnet: str):
        self.ip = ip
        self.mac = mac
        self.gateway_ip = gateway_ip
        self.subnet_prefix = subnet  # e.g. "192.168.1."
        self.arp_table = ArpTable()

    def _is_same_subnet(self, dst_ip: str) -> bool:
        return dst_ip.startswith(self.subnet_prefix)

    def send(self, dst_ip: str, data: str, network: "Network"):
        # 같은 서브넷이면 직접, 아니면 게이트웨이 경유
        next_hop_ip = dst_ip if self._is_same_subnet(dst_ip) else self.gateway_ip

        dst_mac = self.arp_table.lookup(next_hop_ip)
        if not dst_mac:
            print(f"[{self.ip}] ARP Request: {next_hop_ip}의 MAC은?")
            dst_mac = network.arp_request(self, next_hop_ip)
            if not dst_mac:
                print(f"[{self.ip}] ARP 실패 → 전송 불가")
                return
            self.arp_table.learn(next_hop_ip, dst_mac)

        print(f"[{self.ip}] 전송: dst_ip={dst_ip}, dst_mac={dst_mac}, data={data}")


class Network:
    """네트워크 시뮬레이터"""
    def __init__(self):
        self.hosts: dict[str, Host] = {}

    def add_host(self, host: Host):
        self.hosts[host.ip] = host

    def arp_request(self, requester: Host, target_ip: str) -> Optional[str]:
        """브로드캐스트 ARP Request 시뮬레이션"""
        target = self.hosts.get(target_ip)
        if target:
            print(f"[{target.ip}] ARP Reply: 내 MAC은 {target.mac}")
            # 응답 호스트도 requester MAC 학습 (ARP Reply에 포함)
            target.arp_table.learn(requester.ip, requester.mac)
            return target.mac
        return None


# 시뮬레이션
net = Network()
pc_a = Host("192.168.1.10", "AA:BB:CC:11:22:33", gateway_ip="192.168.1.1", subnet="192.168.1.")
pc_b = Host("192.168.1.20", "AA:BB:CC:44:55:66", gateway_ip="192.168.1.1", subnet="192.168.1.")
gw   = Host("192.168.1.1",  "AA:BB:CC:00:00:01", gateway_ip="192.168.1.1", subnet="192.168.1.")

net.add_host(pc_a)
net.add_host(pc_b)
net.add_host(gw)

print("=== 첫 번째 통신 (ARP 발생) ===")
pc_a.send("192.168.1.20", "Hello", net)

print("\n=== 두 번째 통신 (ARP 캐시 활용) ===")
pc_a.send("192.168.1.20", "World", net)

print("\n=== 다른 서브넷 통신 (게이트웨이 경유) ===")
pc_a.send("10.0.0.5", "External", net)
# → 게이트웨이 MAC ARP 조회 후 전송

pc_a.arp_table.show()
```

## 면접 예상 질문

- Q: ARP란 무엇이고 왜 필요한가?
  A: IP 주소로 MAC 주소를 알아내는 프로토콜. L3에서 목적지 IP는 알지만 실제 프레임 전송에는 MAC 주소가 필요하기 때문. 같은 L2 네트워크 안에서 브로드캐스트로 동작.

- Q: 다른 서브넷으로 보낼 때 ARP 동작은?
  A: 목적지 IP가 다른 서브넷이면 게이트웨이(라우터/L3 스위치)의 MAC을 ARP로 조회. 프레임의 dst_mac은 게이트웨이 MAC, dst_ip는 최종 목적지 IP. 라우터를 거칠 때마다 MAC은 바뀌지만 IP는 유지됨.

- Q: VLAN 환경에서 ARP 동작이 달라지는 점은?
  A: ARP는 브로드캐스트이므로 같은 VLAN 안에서만 전달됨. 다른 VLAN 장비와 통신하려면 반드시 L3 스위치 SVI나 라우터를 거쳐야 하며, 각 VLAN에서 별도 ARP가 발생.

- Q: Gratuitous ARP란?
  A: 자신의 IP를 스스로 브로드캐스트하는 ARP. IP 충돌 감지, 장비 교체/failover 시 주변 장비 ARP 캐시 강제 갱신 목적. 스위치/AP 재부팅 후 네트워크 복귀 시에도 전송됨.

- Q: ARP 스푸핑(ARP Spoofing)이란?
  A: 공격자가 허위 ARP Reply를 보내 피해자의 ARP 테이블에 잘못된 IP→MAC 매핑을 심는 공격. 트래픽이 공격자를 경유하게 되어 중간자 공격(MITM) 가능. 대응: Dynamic ARP Inspection(DAI), 스태틱 ARP 설정.
